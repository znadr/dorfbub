Datenschutz

1. Allgemeines
Dies ist eine rein private Webseite. Es werden keinerlei personenbezogene Daten erhoben, getrackt oder analysiert.

2. Datenerfassung durch den Hoster (GitHub Pages)
Diese Website wird extern gehostet über den Dienst „GitHub Pages“ des Anbieters GitHub Inc. (88 Colin P Kelly Jr St, San Francisco, CA 94107, USA). Die Server von GitHub befinden sich in den USA. Deshalb werden Zugriffsdaten, die beim Aufruf der Webseite zwingend benötigt werden, in die USA übermittelt.

Der Hoster erhebt und speichert automatisch Informationen in sogenannten Server-Log-Dateien, die Ihr Browser automatisch an GitHub übermittelt. Dies sind:

  • Browsertyp und Browserversion
  • Verwendetes Betriebssystem
  • Referrer URL (die zuvor besuchte Seite)
  • Hostname des zugreifenden Rechners / IP-Adresse
  • Uhrzeit und Datum der Serveranfrage
  • Übertragene Datenmenge
